Layer 2 — The frontend uses a relative URL.

In artifacts/miaw/src/components/ConversationCanvas.tsx, line 385:

import.meta.env.BASE_URL is set to "/" (Vite default when BASE_PATH isn't overridden). So BASE becomes "" (empty string), and the fetch goes to /api/chat — a relative path on whatever domain the frontend is hosted on.

On Cloudflare Pages, that domain is your-project.pages.dev. So the request becomes:

POST https://your-project.pages.dev/api/chat

Layer 3 — Cloudflare Pages returns 405 for POST to a static path.

Cloudflare Pages is a static hosting platform. It serves files from dist/. There is no dist/api/chat file. For a POST request to a path with no static file, Cloudflare Pages returns 405 Method Not Allowed (it supports GET/HEAD for static assets; POST to a non-existent path returns 405, not 404).
